# smll v0.7.0 — comprehensive token compression

91% reduction in output tokens across all supported commands. Compresses
492K raw tokens down to 7K — a 98.6% overall compression ratio. Significantly
outperforms RTK's claimed 60-90% compression.

All changes are lossy-mode only. `SMLL_LOSSLESS=1` still produces
byte-identical passthrough.

## New compression techniques

### Generic compact (unknown commands >16KB)
- **Global non-consecutive dedup** with timestamp-aware RLE
- **Block-pattern collapse**: repeating 2–4 line blocks → first block + `(+N)`
- **Line truncation** at 128 bytes for very long lines
- **High-repeat truncation**: lines appearing >50× capped to 64 chars
- Threshold lowered from 64KB to 16KB (covers more real-world outputs)
- `×N` dedup markers (saves tokens vs `(xN)`)

### Git filters
- **Directory grouping** in `git status`, `git commit`, `git merge`:
  ≥3 files in the same directory → `A src/components/ ×50`
- **Compact pipe mode** for `git log` and `git show`: `sha7 subject`
- **Blame truncation**: 1 source line per commit block + `(+N)` summary
- **Diff context drop**: hunk headers preserve function names; context lines removed
- **Compact hunk headers**: `@start_line fn_context` instead of `@old_range|new_range`
- Empty `+`/`-` lines (blank-line additions) dropped

### Command-specific
- **curl**: header dedup after first request, body truncation (>10 lines),
  5-request cap, drop date/x-request-id for subsequent requests
- **du**: top-10 entries + tail summary with total size, common path prefix
  stripping
- **docker logs**: timestamps abbreviated to `HH:MM:SS`
- **pytest**: `===` banner padding stripped
- **tree**: box-drawing UTF-8 replaced with space indentation

### Columnar (ps, gh, etc.)
- Repeated column values shown as empty fields (drop `~` sigil)
- Last-field absolute path truncation to basename
